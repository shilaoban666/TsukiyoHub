# 常见问题

## 为什么回答里会说「知识库里没有找到」？

检索结果会经过一道证据闸门：如果最高向量相似度低于 `GROUNDING_MIN_SCORE`，
或者候选片段与问题没有词面重叠，服务就判定知识库里没有相关内容，
如实告诉用户没找到，而不是让模型编一个答案。

## 如何提高检索命中率？

1. 切块大小保持在 500 到 900 字之间，过碎会丢失上下文。
2. 文档标题和段落里写清专有名词，BM25 依赖词面匹配。
3. 用 `POST /api/knowledge/search` 看命中的 `vector_score`，据此调整 `GROUNDING_MIN_SCORE`。
4. 更换向量化模型后必须重新标定阈值，不同模型的分数分布差异很大。

## 支持哪些文档格式？

Markdown、纯文本、PDF、Word（docx）、Excel（xlsx）、PowerPoint（pptx）、CSV、JSON。
其中 Markdown 和纯文本不依赖任何可选库，其它格式需要安装对应的解析依赖。

## 多条消息之间怎么保持上下文？

第一次请求不带 `session_id`，响应里会返回一个；之后每次请求把它带回来即可。
服务会按 `HISTORY_MAX_TURNS` 注入最近若干轮对话，超长时自动压缩成摘要。

## 如何接入自己的前端？

两种方式：直接调用 `POST /api/chat`（或流式的 `/api/chat/stream`），
或者把服务当作 OpenAI 兼容端点使用：Base URL 填 `http://127.0.0.1:8080/api/v1`。
